# 02. 掲載・判定ルール

## 掲載対象

以下を満たす企業を掲載対象とする。

- 日本に拠点がある
- フルリモート勤務可能なポジションが確認できる
- 会社全体がフルリモートでなくてもよい
- 一部職種のみフルリモートでもよい
- 全国勤務可能でなくてもよい
- 出社が一部必要でもよい
- 現在募集していなくてもよい

## フルリモートの考え方

日常の業務を基本的にリモートで行えること。

以下も掲載可能。

- 入社初日のみ出社
- 月1回出社
- 年数回の全社会議
- 必要時のみ出社
- 東京近郊在住必須
- 一部職種のみフルリモート

ただし、出社条件や地域制限は必ず表示する。

## 対象外

- 日本に拠点がない海外企業
- フルリモート勤務可能なポジションを確認できない企業
- 日常的な出社が前提で、フルリモート勤務可能なポジションがない企業
- 根拠がなく判定できない企業

判定できない企業は公開せず、管理画面上の候補 / 要確認として保持可能。

## フルリモート対象範囲

- `all`: 全社
- `partial`: 一部職種
- `unknown`: 不明

## 勤務地域

- `nationwide`: 日本全国
- `restricted`: 地域制限あり
- `unknown`: 不明

`restricted` の場合は `work_location_note` へ条件を記録。

例:

- 関東在住者のみ
- 東京・神奈川・千葉・埼玉
- 指定オフィスへ必要時に出社可能な地域

## 出社

- `yes`
- `no`
- `unknown`

`yes` の場合は `office_note` に詳細を記録。

例:

- 入社初日のみ
- 月1回
- 年2回の全社会議
- 必要に応じて出社

## 情報源

原則、公式情報を優先。

優先度:

1. 企業公式採用サイト
2. 企業公式の働き方 / 制度ページ
3. 企業公式求人一覧
4. 企業公式サイト
5. その他、管理者が信頼できると判断した情報

根拠URLを保存すること。
