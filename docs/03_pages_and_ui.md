# 03. 画面・UI設計

## UI方針

HeroUI v3 を参考にする。

- ライトモードのみ
- シンプル
- 余白を広め
- 過度な装飾なし
- カード / テーブル / Input / Select / Chip / Alert / Button を中心にする
- 状態表示にのみ色を使う
- Chipを乱用しない
- PC優先、スマホでも崩れない
- 色だけで状態を伝えない

---

## 公開ページ

### `/`

トップページ兼企業一覧。

構成:

1. Header
2. Hero
3. 検索
4. フィルター
5. 件数
6. 企業カード一覧
7. さらに表示
8. Footer

Hero:

- 見出し: `フルリモートで働ける企業を探す`
- 説明: `日本に拠点があり、フルリモート勤務が可能な企業を、勤務条件や募集状況と一緒に探せます。`

検索対象:

- 企業名
- 企業概要
- 業種

フィルター:

- 募集状況
- 勤務地域
- 業種

初期表示:

- 20件程度
- 「さらに表示」

企業カード表示項目:

- 企業名
- 業種
- 募集状況
- 勤務地域
- フルリモート対象範囲
- 出社条件
- 最終確認日
- 詳細リンク

### `/companies/[slug]`

企業詳細。

優先表示:

1. 企業名
2. 募集状況
3. 勤務地域
4. フルリモート対象
5. 出社条件
6. 最終確認日
7. 公式採用サイトCTA

主要セクション:

- 企業概要
- フルリモート勤務について
- 勤務地域
- 出社条件
- 募集状況
- 情報の確認状況
- 情報源
- 公式採用サイトへのCTA

CTA優先度:

- Primary: `公式採用サイトを見る`
- Secondary: `公式サイトを見る`

### `/criteria`

掲載基準を説明。

### `/about`

Remotoryの目的と特徴を簡潔に説明。

## 管理ページ

### `/admin`

ダッシュボード。

表示:

- 登録企業数
- 公開中
- 要確認
- 掲載停止
- 変更候補
- 前回一括確認日時
- 全企業更新ボタン
- 最近の更新

### `/admin/companies`

企業管理。

Table:

- 企業名
- リモート対象
- 勤務地域
- 出社
- 募集状況
- 公開状態
- 最終確認日
- 操作

フィルター:

- 企業名
- 公開状態
- 募集状況
- 要確認のみ

### `/admin/companies/new`

企業登録。

### `/admin/companies/[id]/edit`

企業編集。

### `/admin/update`

一括更新。

表示:

- 対象企業数
- 前回実行日時
- 更新ボタン
- 実行中件数
- 変更なし
- 変更候補
- 取得失敗
- 判定不能

残り秒数の予測は表示しない。

### `/admin/reviews`

変更候補レビュー。

企業単位で変更候補をまとめる。

表示:

- 変更対象
- 現在値
- 候補値
- 根拠
- 情報源
- AI信頼度
- 承認
- 却下

### `/admin/errors`

取得失敗 / 判定不能を確認。
