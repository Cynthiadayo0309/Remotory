# 01. プロダクト要件

## サービス名

**Remotory**

由来: Remote + Directory

## 目的

フルリモートで働きたい転職者が、日本に拠点のある企業の中から、フルリモート勤務が可能な企業を効率的に発見できるようにする。

求人情報そのものではなく「企業」にフォーカスする。

## 主な価値

既存のリモート企業一覧との差別化は、以下。

1. フルリモート勤務可能なポジションを持つ企業にフォーカス
2. 出社が必要な場合、その条件を明示
3. 勤務可能地域・地域制限を明示
4. フルリモート求人の現在の募集状況を明示
5. 公式情報を定期確認
6. 最終確認日を表示
7. 判断根拠となる公式URLを表示

## 想定ユーザー

主対象は転職者。

特に以下の人。

- フルリモートで働きたい
- 地方から働ける会社を探したい
- 求人サイトの「リモート可」だけでは条件が分からない
- 今も本当にフルリモートなのか確認したい
- 知らなかった企業を発見したい

## 基本導線

トップ
→ 検索 / フィルター
→ 企業一覧
→ 企業詳細
→ フルリモート条件確認
→ 公式採用サイト

## データ方針

Remotory 内には求人詳細を保持しない。

保持するのは企業単位の情報。

- 企業名
- 企業概要
- 業種
- 公式サイト
- 公式採用サイト
- フルリモート対象範囲
- 勤務可能地域
- 地域制限
- 出社有無
- 出社条件
- フルリモート求人の募集状況
- 最終確認日
- 情報源
- 公開状態

## 募集状況

- `open`: フルリモート勤務可能なポジションを1件以上募集中
- `closed`: 現在フルリモート勤務可能な募集なし
- `unknown`: 判断できない

企業が採用中でも、フルリモート対象求人がなければ `open` としない。
